# Excel任务规则验证

在项目根目录启动现有网页：

```powershell
powershell -NoProfile -ExecutionPolicy Bypass -File .\启动Excel演示.ps1
```

打开 `http://127.0.0.1:8765/rules`，或从首页点击“打开任务规则验证”。此页执行通用的一步条件验证；不会调用设计引擎，也不会将结论自动回写本体。现有案例导入仍使用原来的页面和模板。

## 第一次展示

1. 下载“规则验证示例”，导入，切换T1、T2、T3。
2. T1输入完整，得到“归档能力”和“快速复核能力”。展开规则，查看事实、条件、来源和判断。
3. T2的条件不满足，不推出需求；页面明确说明这不代表确定不需要。
4. T3缺少页数，显示缺少 `pages`；已命中的“归档能力”只作为部分结果。
5. 用Excel将“任务事实”表D3的10改为21，保存关闭后重新导入。T1不再推出“快速复核能力”；原先登记的相关预期用例显示不一致。原始预期不会随运行结果自动修改。
6. 也可以只修改“规则台账”B2的“归档能力”名称。条件仍然成立，但C1、C5会显示“结论不一致”。“对照用例”E列中的预期结论独立保存，不随规则名称自动修改。

此次模板新增“预期需求结论”列。使用旧模板时请重新下载，将预期结论按依据独立填入，不能从本次程序输出自动复制。旧四列表会明确提示更新；不再只核对状态后显示一致。更新程序后请重启原网页服务、刷新页面，再下载新模板。

示例是普通文件审核流程的虚构技术数据，20页分界不是文献结论。此功能完成的是通用输入和解释展示，不代表文章规则已经整理齐。文献的核对范围见 [规则资料台账](规则台账.md)。

## 五张表

| 工作表 | 填写方法 |
| --- | --- |
| 任务 | 每行登记唯一任务编号及说明；允许暂时没有事实的任务 |
| 任务事实 | 每行一项字段，按任务编号关联；字段在同一任务内不能重复；填写类型、原值、单位和来源定位 |
| 规则台账 | 登记唯一编号、需求结论、依据类别、来源文件、原文位置、确认状态及说明 |
| 规则条件 | 同一规则可以多行；各条件同时成立才推出结论；必须至少有一行条件 |
| 对照用例 | 人工独立登记预期规则状态和预期需求结论；可以整表留空，但保留全部五个列名；没有用例时显示未验证 |

保留表名、第一行列名和顺序。输入不执行公式；规则条件不接受Python表达式或任意查询。大小比较支持 `lt`、`le`、`gt`、`ge`；`eq` 表示相等，`contains` 表示事实列表包含给定文本。比较值必须为字面值，不支持多步推导、循环规则或数值单位自动换算。

类型支持“文本、数值、布尔、列表”。数值使用Excel数字单元格，并单独填写单位；无量纲填 `1`。布尔值填文本 `true` 或 `false`；列表填分号分隔文本。空白事实表示信息缺失，0和false均为有效值。已确认规则的比较值不得空白；待确认规则允许留空，并始终不给出确定结论。已停用规则显示 `skipped`。

依据类别为“文献依据、工程约定、技术测试”。程序检查来源是否填写，不检查所填文件真实性或其是否支持该规则。确认状态由资料核对者填写，不能因为程序输出成立就自动标为已确认。未完整到能够登记条件的文献条目先写入资料台账。

## 输出与状态

每次导入在 `generated/rule-reviews/本次编号/` 保存输入Excel、`rule_report.json`、`rule_summary.md`。网页显示该目录及输入SHA256，保存的输入不修改。失败时隐藏旧结果。

规则状态：`pass` 条件成立；`fail` 至少一个条件明确不成立；`unknown` 信息不足或规则待确认；`skipped` 已停用。任务显示“已推出结论、未命中规则、存在待补信息”三种情况；信息不足时已命中项仍是部分结果，不能当作完整需求集合。

对照用例逐项独立比较状态和结论，两者均一致才显示“一致”。预期状态为 `pass` 时必须填写具体需求结论；`fail`、`unknown`、`skipped` 时必须明确填“无结论”，不能留空代替未知的预期。“无结论”是该列的保留标记，不作为需求名称使用。当前每个用例只核对指定任务的一条规则，不验证整个任务需求集合是否穷尽所有规则。

网页、JSON和Markdown摘要同时显示用例数量、一致及不一致数量，以及各项预期／实际状态和结论。JSON的 `case_validation.status` 区分 `passed`、`failed` 和未登记用例的 `not_run`；任务本身的匹配状态独立保留，不因预期写错而改写事实或推理结果。Markdown列出全部用例并标记不一致项。没有用例时不声称验证通过。

本页不宣称规则覆盖了所有需求或资料真实。最多执行100000项条件检查，超过时要求拆分，不截断输出。
