## 模块能力及限制

| 能力 | 当前支持 | 边界 |
| --- | --- | --- |
| 参数目录 | 名称、定义、类型、单位、来源、可选来源定位；可独立校验和查询 | 没有预填具体环境参数，字段均为项目数据管理结构 |
| 当前状态记录 | 保存某参数在某区域、某时间的实际观测值 | 观测时间不是有效区间，不默认代表查询时刻的状态 |
| 时间序列 | 同一参数可有多次观测，支持时间范围查询并按时间排序 | 不插值、不外推、不拟合趋势、不补造缺失记录 |
| 区域 | 区域 IRI、名称、精确匹配 | 无坐标、几何、空间相交或连续分布模型 |
| 类型与完整性 | 必填项、数量、类型、有限数值、单位声明、时区、引用类型及未知字段检查 | 不验证测量真实可靠，不检测所有业务矛盾，不自动换算单位 |
| 来源追溯 | 参数定义来源和观测来源分别返回，可附章节、表号、截图名等定位 | 字符串由数据提供方填写，不自动验证文献真实性 |
| 主本体连接 | 独立 integration 模块提供显式关联校验与查询 | 环境模块不导入主本体，关联仍需实际数据明确提供 |
| 环境作用 | 当前没有作用规则 | 不根据环境记录修改法器属性或生成设计结论 |

“可以存储”不代表“已经具有文章实例数据”；“能够按时间查询”也不等于实现了表 1 所述的发展变化趋势模型。当前没有环境专有参数表，不能声称完整复现了态势概念。

## 本轮完善

1. 增加参数目录的独立校验和查询：尚无观测值时也能核对定义；如果输入包含观测，仍完整校验，不能借此忽略错误记录。
2. 增加可选来源定位字段 `sourceLocation`，明确这是管理元数据，不是文章原始属性。
3. 观测查询同时返回参数定义、参数来源和区域名称，使单位、含义和数值来源可分别追溯。
4. 保留主本体外置和无样例数据的边界，不将新增附件里的法器、任务、结果表混入环境模块。

后续若要填写具体环境参数，应取得其原始定义、单位、区域含义、观测时间和数值来源。仅有场景名称或一段地域描述，不足以编出完整的环境参数记录。
