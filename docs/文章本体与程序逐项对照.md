# 文章与程序的边界

| 内容 | 现状 |
| --- | --- |
| 类、属性、分类词项 | 主本体中已声明 |
| 来源、阶段和单位 | 作为注释保存，来源标注不等于复现验收 |
| 映射、协同规则 | 仅有说明目录，无可执行文章规则文件 |
| 式（1）至式（10） | 仅有公式文字，无计算实现 |
| 自动生成链网 | 未实现 |
| SE、α/β、动态级联 | 未实现 |
| 本体静态检查 | `check_ontology.py`，不能证明符合文章全部语义 |
| 实例校验 | `validate_data.py`，按外部 JSON 配置校验，不是 OWL 推理器 |

自设示例、场景输入和示例执行规则已撤下。保留的具名能力、OODA 阶段和公式目录条目是分类或说明词项，不是预设场景链。
