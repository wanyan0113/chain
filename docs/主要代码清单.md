# 主要代码与配置

核对日期：2026-10-27。路径相对于仓库根目录。当前没有单一 main.py，各模块通过自己的命令入口运行。以下不列测试、临时文件和生成结果。

## 主要模型与程序

| 部分 | 文件 | 职责 |
| --- | --- | --- |
| 主本体 | `killweb_ontology.ttl` | 核心类、属性、关系及规则、公式文字说明 |
| 本体检查 | `check_ontology.py` | 声明、类型、定义域、值域及部分结构检查；也供现有模块调用 |
| 数据校验 | `validate_data.py` | 根据配置检查字段数量、类型与引用；也供环境模块调用 |
| 环境处理 | `environment/loader.py` | 加载、校验和查询区域、参数与观测 |
| 项目联合入口 | `integration/load_project.py` | 联合加载主本体、背景、环境和连接数据，校验与查询显式关联 |
| 来源命令入口 | `source_data/cli.py` | 导入、校验、导出、查询与字段目录命令 |
| 来源导入 | `source_data/ingest.py` | 按配置读取 JSON，建立稳定来源 ID，整理记录与疑点 |
| 来源校验 | `source_data/validate.py` | 校验来源包结构、引用及原值保留 |
| 来源 RDF | `source_data/load.py` | 构建和加载来源 RDF，校验其与来源包的一致性 |
| 来源查询 | `source_data/query.py` | 查询记录、字段原值、材料与疑点 |
| 公共辅助 | `source_data/common.py` | JSON 读取、摘要、ID、报告与安全写出 |
| 字段目录 | `source_data/dictionary.py` | 生成来源字段目录，不建立业务属性映射 |
| 来源适配 | `adapters/source_to_rdf.py` | 对固定来源 RDF 契约的配置一致性封装 |
| 环境适配 | `adapters/environment_to_rdf.py` | 环境 JSON 转 TTL，或读取并校验已有环境 TTL |

## 直接影响程序行为的模型与配置

| 文件 | 作用 |
| --- | --- |
| `source_data/ontology.ttl` | 通用来源 RDF 的类、属性和关系 |
| `source_data/schema.json` | 来源包结构 |
| `source_mappings/article_source.json` | 原始来源 JSON 的读取映射 |
| `adapter_mappings/source_metadata.json` | 来源 RDF 适配契约 |
| `adapter_mappings/environment.json` | 环境输入结构与适配配置 |
| `environment/ontology.ttl` | 区域、参数、观测及属性定义 |
| `environment/profile.json` | 环境应用层校验要求 |
| `integration/environment_mapping.ttl` | 态势与环境观测的显式连接关系 |
| `requirements.txt`、`source_data/requirements.txt` | 项目及独立来源模块的依赖要求 |

## 辅助工具（不作为日常主流程入口）

| 文件 | 作用 |
| --- | --- |
| `source_data/inventory.py` | 提取现有本体具名类、属性及来源结构清单；不建立业务映射 |
| `adapters/check_project.py` | 分类验收来源、环境和项目背景，分别记录默认与严格观测模式结果 |

## 阅读与运行顺序

来源处理从 `source_data/cli.py` 开始，沿 ingest、validate、load、query 阅读；环境接入先看 `adapters/environment_to_rdf.py` 和 `environment/loader.py`，再看 `integration/load_project.py`。具体命令见 `source_data/README.md`、`adapters/README.md` 和 `integration/README.md`。

来源处理入口和项目背景联合入口分别运行，目前没有串联全部步骤的统一入口。integration 不会自动执行来源导入和环境适配；来源追溯由独立来源查询负责。

`data/` 保存输入资料，`generated/` 保存生成结果。当前已提供来源整理、环境适配与显式关联查询；规则和公式文字不等于可执行算法，尚未实现链网生成、指标评分、环境作用计算、SE 计算、α/β 拟合或级联仿真。
