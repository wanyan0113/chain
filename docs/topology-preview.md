# 依赖边变更的只读影响预览

对应优化清单第3项“映射审计”的结构影响预览。它回答“若变更这条登记候选，哪些方程、输入条件和下游需要重新检查”，不回答“变更后误差是否更低”。不是T-Frozen或T-Refit，不调整正式拓扑，不运行拟合或SE生成。

## 审查内容

- 从已登记候选id提出增删，核对产品生产/消费、直接通道、共享状态所属链和登记状态。通道或间接可达不自动成为依赖依据。
- 提案同时绑定规范化源拓扑摘要与原审计依据摘要；任一变化都拒绝旧提案。预览另有稳定preview_id。
- 列出根节点前后变化、改变入边的接受节点、下游可达集合和传播路径。路径有显式数量上限与截断标记；可达集合完整计算。
- 明确列出“入边改变仍有输入、需重新拟合的局部方程”和“失去全部输入、需另定预测策略的节点”。入边未变的下游不自动要求重拟合，但整网预测须重新计算。
- 被直接改边节点禁止直接套用旧参数，包含SOD均值项数变化的情形；保留原评价目标，不静默删除目标来改善指标。

删除唯一入边会使原接受节点成为根，现有通用入口可能读取其观测值。这会增加原来没有的外部信息。预览强制列入requires_explicit_root_policy，要求后续明确训练侧无依赖预测或新的外部输入证据；不会自动执行。
原根新增入边也改变信息集与方程，需要重新登记条件。全部删边可做结构审查，但不能直接送入当前拟合入口。

## 提案格式

```json
{
  "id": "review_remove_T1_flow_0",
  "source_network_sha256": "规范化源拓扑的digest",
  "source_sidecar_sha256": "原衔接依据与审查JSON的digest",
  "remove": [{"candidate_id": "T1_flow_0", "rationale": "本次变更审查依据"}],
  "add": []
}
```

`fdna.structure.digest`用于摘要，拓扑先经`fdna.topology_preview.canonical_network`规范化；节点与边的排列不影响网络身份。不要以人工复制不明摘要或删除摘要字段绕过绑定。
06演示命令会生成完整、已绑定的proposal.json，可基于同一源资料修改说明后重跑。

```powershell
# 从.publish/fdna-bridge运行；输出目录必须不存在或为空
& '..\..\.venv\Scripts\python.exe' -B workflow_tools/run_topology_preview_cases.py --source-dir '..\..\generated\关于两篇连接\06_完整场景全流程运行' --output-dir '..\..\generated\关于优化\05_依赖边变更影响预览'

# 重跑单个已绑定提案，另用新的空输出目录
& '..\..\.venv\Scripts\python.exe' -B -m fdna.topology_preview --network '..\..\generated\关于优化\05_依赖边变更影响预览\源拓扑.json' --sidecar '..\..\generated\关于优化\05_依赖边变更影响预览\源审计依据.json' --proposal '..\..\generated\关于优化\05_依赖边变更影响预览\案例\remove_T1_flow_0\proposal.json' --output-dir '..\..\generated\关于优化\预览_新运行'
```

状态review_required表示结构预览可供继续审查，不是修改获批或可直接分析；semantic_blocked表示候选缺少消费、通道或受登记状态/跨链边界阻断。CLI前者退出0，后者保存阻断说明并退出2；环路、旧摘要和非法提案拒绝生成结果。
输出只有提案、结构预览和说明；不导出名为“输入_拓扑.json”的可执行网络，不更新候选审查状态，不调用拟合器。

## 验证

13项新增测试覆盖唯一入边删除、多输入增加、替换、根变化、环路、产品/通道阻断、旧摘要、路径截断、输入不变和不调用拟合器。包含桥接、诊断、基线与稳定性的110项相关测试全部通过。
06案例另用独立传递闭包算法核对根、父节点和下游集合，前后复核94文件源包；6个单边删除、3个无消费捷径、1个全边删除，全部保留原始正式结果。
这补齐结构审查功能，不等于已经开展替代拓扑的数值敏感性、真实依赖验证或通用跨链桥接。
