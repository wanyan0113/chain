# 固定数据下的求解起点种子敏感性

本步推进优化清单第5项，针对论文分析报告的C2初值敏感问题。此前08改变训练样本构成但固定求解种子；本步固定原06全部数据、90个训练与30个留出基础样本、三种环境、模型、边界和求解器，只改变随机起点种子。

计算前登记`data/fdna/solver_seed_protocol.json`：原种子20261122为控制，另选四个固定种子2026112401至2026112404；每次仍为一个中性起点、五个随机起点，L-BFGS-B、1500上限。各起点只按训练损失及原有浮点并列规则选择，完整保留所有起点；不跨种子挑选模型，不读取留出误差选种子、不热启动。

5个种子共180次局部拟合，其中36次为原种子控制、144次使用新种子；不是180个独立数据实验。控制复现90个参数与8640个预测数值，最大差0。正式06包94文件前后摘要一致。

## 复跑

从`.publish/fdna-bridge`运行，输出目录须不存在或为空。示例复跑写入新目录，保留第一次成果：

```powershell
& '..\..\.venv\Scripts\python.exe' -B -m fdna.solver_seed_sensitivity --source-dir '..\..\generated\关于两篇连接\06_完整场景全流程运行' --protocol data/fdna/solver_seed_protocol.json --output-dir '..\..\generated\关于优化\17_求解起点种子敏感性_复跑'
& '..\..\.venv\Scripts\python.exe' -B -m workflow_tools.verify_solver_seed_sensitivity --report-dir '..\..\generated\关于优化\17_求解起点种子敏感性_复跑'
```

运行器生成逐种子记录、JSON报告、四份CSV和两张PNG/SVG。核验脚本独立使用标量公式和统计计算，不调用拟合器或本步摘要函数。首次结果和解释保存在`generated/关于优化/17_求解起点种子敏感性`；图文及核验摘要见[结果快照](solver-seed-report/README.md)。

## 解释边界

这五个种子只是固定六起点机制的有限诊断，共享同一中性起点，不是五组完全独立的初始点设计。种子变化会同时改变多个局部方程的随机起点，因此递推差异不能单独归因于某个参数。最小/中位/最大不是置信区间；数值变化阈值1e-8不是应用容许误差。

保留原求解器，没有覆盖其他算法、更多起点数量或PCA初始策略。使用的留出集已经被查看过，不是新独立测试，不用本实验宣称FDNA优于OLS。原正式模型不被替换；有效参数/传播区间与真实数据验证仍未完成，第5项整体仍为部分完成。

本步没有重算各新种子的完整退化传播，不用普通预测稳定代替传播稳定性。原七个发布包的统一目录保持原登记，本成果使用上述独立核验入口。
