# 共同绝对强制值下的种子模型传播对照

本步继续推进第5项，回应18号相对退化分析的解释边界。原方案给每个模型强制“自身基准×比例”，同一比例可能对应不同绝对值；本方案按原种子20261122的预测基准确定强制值，在同一环境、模型类别、基础样本、干预节点和比例内，五个种子接受完全相同的绝对值。跨环境、模型类别、基础样本的强制值不必相同，原种子也不被视为真实值。

计算前固定`data/fdna/absolute_seed_protocol.json`，保留原五种子、六任务、九组可达关系、五档比例和30留出基准，新增40500条共同绝对值响应，并与18号40500条相对响应配对。没有拟合、生成SE、改边、挑选种子或覆盖旧包。

目标减少量定义为“该种子自身目标基准减去共同强制值后的目标输出”。共同值高于某新模型自身干预节点基准时，输出可能增加，减少量可以为负；比例1不被当作所有模型的恒等操作。负值不截断，不能因名称叫退化就删除这些响应。

## 分开比较两种差异

对同一种子，先固定模型，只改变干预值，记录“相对减少量−共同值减少量”。再固定共同干预值，跨种子记录“目标基准差”和“同强制值目标输出差”；共同值减少量相对原种子的差，等于前者减后者。这是配对代数分解，不是单参数因果识别，各跨度也不能直接相减求贡献。

预设示例沿用09/18的env_0/自由δ/B1→F1，不按本轮结果重新挑选展示条件。图中保留无明显参考值影响的预设结果，对小于1e-8的数值差明确注明，不将微小误差视觉放大。

从`.publish/fdna-bridge`运行，使用新的空目录：

```powershell
& '..\..\.venv\Scripts\python.exe' -B -m workflow_tools.verify_absolute_seed_propagation --report-dir '..\..\generated\关于优化\19_共同绝对值传播对照_复跑'
```

独立标量脚本重新计算共同值与相对响应、配对分解、原种子/零值/根干预控制、非后代不变、输出越界/供给外推和负减少量，未调用生产传播实现。输出保存两张PNG/SVG、完整NPZ及掩码、270行条件摘要、1350行配对种子均值。首次文字说明与全部结果见`generated/关于优化/19_共同绝对值传播对照`，[公开图文快照](absolute-seed-report/README.md)也保留完整数组。独立复核需要本地06/17/18来源。

240项不同相关测试通过。固定绝对值只控制了干预输入，多个方程参数和各模型自身目标基准仍可不同；这些比较不证明真实因果、参数唯一或有效置信区间。第5项仍部分完成，原七包统一目录保持原登记，本成果通过上述独立入口复核。
