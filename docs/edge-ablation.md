# 同信息、同目标的训练均值依赖消融

这是优先级第8项的一个受限数值拓扑实验，承接05只读预览。它实际在独立子图中计算预测与传播；正式06图、产品消费登记、原参数和原始SE均保留。

## 假设与公平性

运行前登记`data/fdna/edge_ablation_protocol.json`：对A1→B1、A2→B2、A3→B3、B1→F1、B2→F2、B3→F3逐条消融，并做全边消融。加上原模型共8个情景，全部运行，不按留出结果挑边或挑最优图。

每个接受节点只有一个供给。删除唯一入边后，它虽然成为图论上的根，仍是原评价目标；使用同环境、原90个训练基础样本的目标均值作为显式预测，不读取该新根观测。原30个留出基础样本保持不变。全部六个接受节点继续评价，整网递推只获得原A1/A2/A3外部观测。

局部评价仍与原方案一样获得该目标原直接供给观测，因此局部与整网递推分开报告。切断节点在两种评价中都用训练均值；不切断节点使用原方程。没有增加任何新根真值输入。

## 参数处理及解释

这不是把原接受方程直接套到零输入：改边接受节点的α/β/δ方程被整体移除，以训练侧估计的一个常数替代。未改边方程在其供给、局部观测训练数据和求解设置均不变时冻结。18个环境×目标均值在两种模型间共享，每个使用90条训练记录；训练常数计1个名义参数，不能称零参数。

本步命名为“剩余方程冻结、训练均值替代的依赖消融”，属于明确根策略后的受限数值拓扑诊断；不是完整T-Refit或新结构最优拟合。没有调用FDNA求解器，也没有按无依赖假设重新生成数据。

全部原9组可达关系保留用于传播对照；子图中不可达的关系另作标记并检查零响应。每情景以自己的预测为基准，保留五档比例。比例0的绝对强制值都是0，非零比例不保证不同情景的强制值相同。新常数根也允许被显式干预，干预时暂停其常数方程。

## 运行结果与验证

[两张图与说明](edge-ablation-report/结果说明.md)展示同目标递推RMSE变化与固定env_0/自由δ/F1的置零传播。六个单边情景的受影响递推留出比较每种模型27组：自由δ全部更差，基础式24组更差、3组更低，近等按已有1e-8口径。这些重复使用同一留出集的条件比较不是独立实验，不作显著性解释。

155项相关测试通过。独立标量核验18个训练常数、69120个预测值、64800条响应、18900次断路零响应、1152行误差和2160行传播摘要；最大数值差约2.84e-14。原06全部94文件保持一致，原模型8640个预测复现。

此对照只回答“用训练常数替代依赖输入后，既有模型如何变化”。它不能证明真实边成立/不成立，不能推翻OLS基线比较，也不能推广为FDNA的普遍优势。05提案的待审状态未改变，正式映射未获自动批准。
