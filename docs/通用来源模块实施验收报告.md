## 技术及异常验证

执行 `.venv/Scripts/python.exe -m unittest discover -s tests -v`，19 项测试全部通过。验证内容包括：

- 全部真实来源行、字段原值、材料及疑点可查回；重复导入和 JSON 对象键重排不改变来源对象与引用。
- null、缺失键、布尔值、数值、嵌套对象和数组保持区分；未知单位与未确认单位不当作无量纲。
- 错误路径、脚本表达式、重复路径、重复原行标识、疑点悬空字段及未知材料报错。
- 来源包原值、状态、规范化值及引用被篡改时失败；RDF 缺失类型、多余成员、错误引用及未知来源属性失败。
- 输入摘要变化会被检测；输出默认不覆盖，失败预检不写入新结果，显式覆盖按文件原子替换，禁止写入来源目录和路径穿越。
- 单独复制 source_data/ 到临时独立目录，在没有主本体、adapters/、environment/、integration/ 和根目录工具的情况下加载、查询成功。
- 只有区域时通过；装备表作为环境 JSON 时失败；缺必填项、无时区时间、未知参数或区域、阻塞疑点、NaN、缺单位、整数小数及重复环境 ID 均失败。
- 临时技术观测通过既有环境加载、查询和显式 hasObservation 严格联合路径，返回 observation_linked；这些技术数据已随临时目录清除，未作为真实观测验收。

## 运行与限制

完整运行命令见 `source_data/README.md` 与 `adapters/README.md`。所有新增命令 stdout 为 JSON，诊断 stderr；0 成功、1 数据无效、2 输入或命令错误。`--overwrite` 必须显式指定；每文件原子替换，不提供跨文件事务。

来源包当前是经过映射验证的不可变归档快照，不提供人工审核编辑器或自动疑点解决。normalized_value 保持 null；要记录后续人工解决或转换结论，应先扩展显式审核输入契约。来源入口一次处理一个完整来源包，可分成多个本地 TTL 文件，不提供多包联合目录。

已有区域的 rdfs:seeAlso 指向外部截图来源，按原样复用；未按名字把它与本次来源包材料或任务自动合并。来源引用用于追溯，程序不验证外部材料真实性，也不扩充现有项目查询的来源元数据结构。

本期交付止于来源管理和区域／环境接入。现有真实材料没有独立观测，不将技术测试写成真实案例通过，不把表 7—11 宣称为已经接入攻击链推理的业务输入。
