# 两篇方法与当前软件的接口语义及适用范围

本说明以代码81e949e和06完整场景结果为依据。原论文思想、软件已有能力和本次实际验证分别列出，不以“代码中存在功能”代替“实验已覆盖”，也不将模拟登记等同真实依赖确认。

## 一、当前最准确的定位

建立两篇论文关键流程之间的可验证接口：上游生成已选装备网，经任务产品定义和显式假设登记转换为能力依赖图，再接入观测SE拟合与模型内传播分析。

当前证据支持特定格式的半自动衔接与合成实验验证，不支持“两篇论文全部方法和实际案例已完整复现”或“任意装备网可自动生成真实能力依赖图”。

## 二、逐环节对应

| 方法环节 | 当前软件能力 | 06场景实际验证 | 边界 |
| --- | --- | --- | --- |
| 上游任务—能力—装备知识 | 本体、具名能力和规则驱动筛选 | 新知识条目经HermiT推理，按甲乙丙标签筛选六主体 | 标签与能力事实由合成输入和知识配置提供，非从实测自动发现 |
| 装备协同与连接 | 角色、通道、控制及资源条件检查 | 三角色通道与单窗口容量核验 | 不代表原文全部协同规则均已启用或全部动力学已实现 |
| 连点成链、聚链成网 | 候选链组合与资源检查 | 实际8条链、16种组合、4种可行网 | 验证的是当前三角色、每角色单装备计划组成的网 |
| 候选链评价和选择 | 引擎存在时间、精度、成本及权重评分 | 活动指标同值占位，可行网同分，独立语义排序核对首个组合 | 当前场景不是原文多指标最优选择流程的完整复现；不意味着引擎只有稳定排序功能 |
| 装备主体到能力实例 | 映射草稿、状态身份、来源绑定和登记校验 | 按主体＋功能＋任务产品建立A/B/F状态 | 一个装备不直接等于一个能力节点；同主体的不同任务产品可分别定义状态 |
| 能力依赖识别 | 检查直接产品消费与通道证据，保留待审或拒绝关系 | 登记6条直接消费边，心跳和捷径不导出 | 软件验证登记与结构一致性，不证明真实因果；草稿仍需人工确认 |
| SE指标与计算 | 多种生成机制和外部观测SE接口 | 条件合格事件计数，比例×100，得到360条记录 | 信息、指令、回执质量是合成代理指标，不是原文实际任务效能数据 |
| FDNA参数求解 | 基础公式、固定/自由δ设置、按节点拟合、多初值与诊断 | 基础式和自由δ，36次局部拟合 | 本例没有固定δ组；默认中性/随机初值，不声称复现原文PCA到参数起点的映射 |
| 递推和依赖分析 | 局部/整网预测、节点退化与结构路径 | 270条标准退化响应、另180条已知合成H情景 | 静态模型内重算不等于实际干预因果或时间演化仿真 |
| 复现与验收 | 输入、代码和结果快照，事件审计，完整包校验与比较 | 独立环境复跑，关键数据和数值结果一致 | 软件和计算一致性不证明真实任务有效性或学术新颖性 |

## 三、需要始终区分的关系

1. 装备通道可用，不等于能力间必然存在直接效能依赖。
2. 直接产品消费，是当前登记依赖的依据；其实际影响还需要相应数据验证。
3. 共享主体是状态身份或共同条件关系，不自动增加跨任务FDNA边。
4. 容量限制是当前组网可行性条件，不自动变成SE中的拥塞、竞争或时延效应。
5. 图中没有跨任务边，不代表共享H造成的统计相关不存在。
6. 结构路径可达，不保证每个基准下都发生数值变化；边变更后的结构影响也不等于真实因果影响。

## 四、当前结构覆盖

上游桥接：支持多条三角色、每角色单装备的链组成的网，并显式登记共享主体。当前06能力图是三个没有跨任务供给边的任务分量。

数值引擎：已有3输入、5输入及11节点18边的代表性验证。因此，桥接接口的结构限制不能等同于FDNA引擎只能算单输入。

同角色多装备联合活动、复杂跨链消费、反馈及动态资源竞争尚未在桥接流程中通用实现。若研究主张只是当前格式下的流程衔接，可后置；若主张更通用的转换方法，则需要提前选择明确的新结构补充验证。

## 五、用词约定

- “已登记工作假设”：通过本项目登记与结构检查，不等于真实依赖已确认。
- “输入事实”：来自输入记录的声明；来源可能是合成设定，不能仅因称为事实就当成实测。
- “拟合完成”：程序得到参数与评价结果，不等于参数唯一、稳定或物理解释充分。
- “预测可用”：需要预先定义用途、容许误差和适用输入范围，不能只凭优化器成功或较低RMSE自动宣布。
- “模型表达不足”：需要相应结构或实验依据，不能仅由秩不足推出。
- “δ作用”：原文提出修正归一化可能引入的误差；吸收其他失配是项目中的诊断假设，不是原文已证明的物理解释。

建议汇报表述：“实现了知识规则生成的装备网与任务能力产品依赖图之间的半自动衔接，并在明确合成假设下验证数据生成、参数拟合和传播计算。当前结论适用于已登记结构与数据条件，真实依赖和实际效能仍需外部数据校准。”
