# 50轮训练成组重采样后实际重拟合

[两张图与解释](结果说明.md) · [参数变化](参数变化摘要.csv) · [诊断频次](诊断频次.csv) · [固定留出误差](固定留出误差摘要.csv) · [独立核验](独立标量复核.json)

本步实际重新估计实验模型，区别于此前04/07的冻结模型分析。原正式参数及SE仍保留，原30个留出基础样本未进入训练。90个训练基础样本成组抽样90次，共50轮；所有环境与模型配对，保持原求解器、6起点、种子及边界，不热启动。

1800次局部拟合均成功，但1588次局部秩不足、1745次有多初值跨度、545/900次自由δ触界。成功不等于参数可靠，范围也不作置信区间。每轮实际不同训练基础样本49至65个，重复观测不是新的独立样本。

124项相关测试通过。原训练控制90个参数及8640个预测数值完全一致。独立标量核验10800个起点训练损失、4500个选中参数值、108000个留出预测值和486个摘要值，最大差约2.84e-14；每次初值集合及设置摘要均与原设置相同。

一个说明边界的例子：env_0.6/F1基础式每轮均为α=1、β=50，预测恒等于供给值，固定留出RMSE恒为6.13256。这不自动证明稳健或唯一，亦不等于已记录的结构下界5.26941。不要把低波动、成功返回或某个参数中位数当作实际物理正确性。

方法与复跑命令见[固定方案](../training-refit.md)。全部逐次模型、起点记录、抽样索引和留出预测保存在本地08包，源码不重复上传全部记录。未开展有效参数区间、另换种子/求解器的完整诊断或重估模型的全传播不确定性。
