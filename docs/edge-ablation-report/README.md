# 同信息、同目标的依赖消融

[两张图与解释](结果说明.md) · [全部误差对照](同目标误差对照.csv) · [全部传播对照](同关系传播对照.csv) · [独立复核](独立标量复核.json) · [方法与命令](../edge-ablation.md)

在原六条单供给依赖上分别移除一条边，再做全边移除；加原模型共8个情景。失去入边的节点用原训练集目标均值预测，继续保留为评价目标，不读取新增根的留出观测。整网递推仍只使用原A1/A2/A3根输入；局部评价按原方案获得目标直接供给观测，两层分开。

对每种模型，六个单边情景共27组受影响的递推留出比较。自由δ：27组误差更高；基础式：24组更高、3组更低（沿用1e-8近等口径）。这些条件重复使用同一留出集，不是27个独立实验，不能用于显著性、真实依赖识别或方法选择；不改变此前与OLS基线对照的结论。

没有新增FDNA拟合。被切断接受方程整体替换为训练均值；其余方程因供给、观测训练数据和设置未改变而冻结。18个训练均值各使用90条训练记录，每个计1个名义参数。这是受限冻结方程消融，不是完整T-Refit或替代结构的最优拟合。

155项相关测试通过。独立标量核验18个训练常数、69120个预测值、64800条传播响应、18900次断路零响应、1152行误差及2160行传播摘要，最大数值差约2.84e-14。原06包94文件与原8640个预测均复核一致，正式图与提案待审状态保持原样。

本快照含PNG/SVG、完整报告、CSV、协议、训练常数、名义维度、完整NPZ与独立审计。NPZ轴标签在ablation_report.json的axes中：predictions=[情景,模型任务,全部基础样本,原评价目标,局部/递推]；target_values=[环境,全部基础样本,原评价目标]；decrease/changed/forced/extrapolated=[情景,模型任务,原可达关系,比例,留出基础样本]；baseline=[情景,模型任务,留出基础样本,节点]；structurally_reachable=[情景,原可达关系]。decrease为正表示SE减少。不可达关系保留并核对零响应，不伪装成可达；目标无供给时覆盖提示不适用。

同样比例使用各情景自己的预测基准；比例0强制值均为0，非零比例不保证绝对值相同。路径断开后的零响应来自模型定义，不证明真实系统没有影响。没有重生成无依赖假设数据，也没有自动撤销真实产品消费关系。

精确字节可用manifest.json核对；重新独立核验需要本地原06来源包，报告中绝对路径仅用于本次来源定位。第8项已推进到受限数值消融，多输入、完整替代结构重估和真实数据验证仍未完成。
