# 冻结预测的基础样本成组重采样：固定方案

2026-11-23，计算重采样结果之前登记。配置为`data/fdna/prediction_stability_protocol.json`。

## 本步问题与边界

针对已完成的简单基线对照，检查留出样本构成变化时，各模型预测误差及配对误差差值如何变化。
本步是优先级文档中“稳定性量化”的一部分，只涉及冻结预测；不是重新估计参数的bootstrap，不提供α/β/δ置信区间，也不量化传播干预的不确定性。

固定使用已验证的03核验版预测，不重拟合、不选择模型、不生成SE、不改变06场景。
原有留出结果已经被查看；本次继续属于追加描述，不能当成新的独立测试或显著性检验。

## 抽样单位

从30个留出`base_case_id`中有放回抽取30次，重复2000次，固定种子20261123。
每一次抽样的索引同时应用于全部环境、节点、方法、局部和递推预测；保留基础样本内的联合关系，不分别抽样环境或节点。
每个环境内保留完整的任务产品节点，不把90条环境配对观测或200次微观事件当成独立网络样本。

严格检查基础样本不跨训练/留出、样本身份不冲突、各环境/节点/方法的留出面板完整、对应目标一致。
缺失或受阻面板明确拒绝，不静默删除以改变评价集合。未来需要处理不完整面板时另行登记方案。

## 输出与解释

逐环境×节点×局部/递推保存4种方法的RMSE、MAE原值与重采样分布，输出2.5%、50%、97.5%分位数。
配对比较固定为OLS−自由δ，以及自由δ−基础式；差值先在每个同一次重采样中计算，不能用两方法边际分位数相减。
负值表示前者误差更低。另输出负/近零/正的重采样次数，近零数值阈值1e-8沿用基线口径。

“中央95%经验范围”只描述当前30个留出基础样本、当前冻结模型下的重采样波动；不称参数置信区间，不作显著性检验，不把负值频率称为方法优越的概率。
多个节点/环境的范围不是同时覆盖区间。没有研究新的真实数据总体、训练数据或拟合起点不确定性。

保存每次抽样索引、完整逐次指标和配对差值，支持独立标量复核。输出目录必须不存在或为空；不调整重复数或种子追求结果。
