# 阶段三第一项验收：受控分类正确率

用户选择先验证受控分类，不混入任务成功阈值或连续误差；阶段二-B按评审关闭。当前阶段仅解释 `sequential_product_v2` 对二元正确事件的预测适用性，不改变旧评分、网络优化或精度公式。软件正确计算数学模型，不代表数学模型正确描述现实系统。

## 冻结的设计与判定

实验开始前冻结protocol.json及生成器/分析器/原始评价函数摘要；源码变化后拒绝执行旧协议，不根据结果调整种子、容差或样本量。

- 19个场景，每场景5个固定种子；每次独立校准5000个样本、串行评估10000个样本。每个环节的单环节率来自独立校准集，同一串行样本贯穿全部环节。
- 主要结论按同一场景的5批汇总：每环节校准25000个样本、端到端评估50000个样本；另列全部5批结果及误差方向。不同场景/人群/流程不混池。
- 第一轮受控筛查可接受绝对预测误差为 **0.05，即5个百分点**。这不是原论文参数，也不是未来真实业务验收标准。
- 单率列名义95% Wilson区间。主判定对L个校准边际率及端到端率各用alpha=0.05/(L+1)的Wilson区间，构成Bonferroni保守包络。乘积区间由非负概率区间的上下界相乘；偏差区间为[实测下界−预测上界，实测上界−预测下界]。这是按场景的名义95%近似置信包络，不声称19场景家族同时95%覆盖。
- 偏差区间完全位于[-0.05,0.05]才判“当前容差内等效”；完全高于0.05判乘积系统性低估，完全低于-0.05判系统性高估，且5个种子的误差方向必须一致；其余为证据不足，不能用“不显著”代替通过。
- 校准/评估每个声明的难度分层×真实类别至少100个样本；缺标签、重复身份、缺评估结果直接阻塞。校准与评估人口定义不同的负控制必须标为人群不匹配，不能当作模型有效检验。

## 可观测对象

每个样本具有预先生成的二元真实标签。环节实际处理标签，返回0、1或拒判x；拒判计为错误，不默默剔除。保存故障注入日志、每环节正确输入下的影子探针输出，以及串行实际输出。影子探针使用同一受控故障状态，提供可审计的单环节事件；现实中不一定能取得这些反事实探针，不能假装已有真实测量。

校准集仅测各环节正确输入下的输出；评估集不参与预测参数拟合。每个样本和种子身份独立，不混用校准/评估。端到端正确率由最后实际输出是否等于真实标签统计，不直接从乘积概率抽取终点标签。生成器不调用生产评价公式决定实际标签。

环节误差相关性使用同一样本各影子探针的错误事件，而非已经传播后的累计输出错误；后者即使在独立通道也会相关。记录配对列联表和phi，方差为零时为null，不能伪造为零相关。相关系数不单独估计置信区间，主判定依赖上述率与偏差包络。

## 数学语义与结论边界

链式法则 `P(S1∩…∩SL)=P(S1)∏P(Si|S1…Si−1)` 不要求独立。但是当前固定单环节属性若是独立校准的边际率，不能自动充当这些条件率。即使单环节故障独立，后续纠错也会使“最终正确”不同于“全过程每步正确”。

记录按前缀正确条件测得的条件率及其乘积，它只复算同一评估集的全程正确频率，是样本内恒等式，不能拿来作为独立预测验证；遇到零条件样本返回null。

本轮是合成标签和明示故障机制下的实际算子执行，**不是现实法器的观测实验**。独立标签重放只证明数据符合所声明的受控机制。无论控制组是否通过，真实领域有效性保持pending；相关或纠错反例可以否定乘积普遍适用，不能证明某篇论文或某个真实系统必然错误。连续精度、融合与新评价政策另行设计。
