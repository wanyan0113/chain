# 阶段三：串行多环节精度模型的领域有效性验证

第一项为用户确认的**受控分类正确率检验**；阶段二-B按评审关闭，本轮没有继续细分性能或加入持久JVM。结果见[受控实验报告](results-v1/README.md)。真实领域有效性仍为 `pending`，不能把这份报告称为真实法器精度验收通过。

当前程序仍按 `sequential_product_v2` 对环节accuracy连乘，原生产源码、公式、归一化、候选身份和组网约束均未修改。本轮分析器调用原始指标函数得到预测值，另对留出样本实际执行受控标签算子，统计最后输出是否正确。

## 验收范围

19场景、每场景5个固定种子；95个独立数据文件共1425000个样本观测。对每个场景合计25000个校准样本、50000个串行评估样本，全部原始CSV压缩归档并独立重放。样本数、5个百分点筛查容差、名义95%置信包络、分层覆盖、系统性偏差的方向判定均在运行前冻结，见[实验协议](protocol.md)。

这是合成样本、明确故障机制下的标签传递/核对实验，没有训练真实领域分类器，没有真实特征采集或真实法器测量。独立控制、共享难度、互斥错误、同一算子重复、翻转抵消、后续参考纠错和人群不匹配分别测试。独立故障/失败吸收组是检查框架的正控制，不能作为“模型已描述现实”的证据。

校准与评估互不重用。每个串行样本经过全部步骤；正确输入影子探针记录每环节在相同故障状态下的单环节输出。相关性用影子探针错误计算，不能把传播后的累计错误相关性误认为局部故障相关性。影子探针及参考纠错需要受控可信标签，在真实系统中是否可取得仍须核实。

8项针对性的验收测试覆盖独立正控制、相关与互斥错误、独立错误抵消、后续恢复、零方差相关性、缺失/重复标签及协议摘要保护。数据重放与统计复算另行覆盖全部95份原始文件，不将其数量冒充软件测试数量。

连同原联合评价回归，共19项相关测试通过，包含上述8项，不能累加为27项。19组场景的结论为：8组在冻结容差内等效、9组乘积低估、1组高估、1组因人口不匹配阻塞；这些结论只针对所声明的受控机制。

## 对当前精度政策的含义

乘法至少涉及三个不同问题：环节accuracy代表什么事件；各环节率是否适用于同一总体和相同输入条件；最终成功是否必须每一步都正确。只有软件乘法计算正确，不能回答这三个问题。

链式法则无需独立：若每个值是“此前均正确条件下，此步也正确”的概率，其乘积对应全程正确；但固定法器属性不自动成为这些条件概率。重复同一算子时，已知第一次正确后下一次的条件成功率可以接近1，不能照搬边际率再次相乘。存在纠错时，全程正确与最终正确更是不同事件。

对后续解析/复核环节，值得另行收集 `P(输出正确|输入正确)` 与 `P(输出正确|输入错误)`，再评估状态转移模型：

`q_i = q_(i-1) * p_i + (1-q_(i-1)) * r_i`

该式还需要状态/历史信息足够的假设；共享难度时应按分层或更完整历史建模，不能自动用它替代一切。它只是后续研究方向，本轮未新增评价政策或改动现有评分。

受控反例可限制乘积的普遍解释，不代表原论文必错。若原文精度是空间误差、连续偏差或其他定义，必须重新确定量纲、组合规律及领域标签，本轮不跨定义外推。

## 后续真实领域数据的最小条件

先确定每个输出的独立真实标签及获取方式、环节/法器版本、人口/难度分层、采样方案、错误输入的出现和后续修复方式。必须保存同一样本贯穿环节的身份，校准与评估分开；缺失或未执行不得伪装为错误或成功，须单独记录并阻塞当前完整样本分析。

本轮压缩CSV接口有严格列头：`sample_id,split,stratum,gold,fault_bits,shadow_outputs,serial_outputs`。这是**受控机制专用契约**，真实数据未必有故障或影子日志，不能为了适配而伪造；真实导入器需按可取得的自然观测另行设计。当前reader验证结构和重复身份，不等于证明人口标签或独立性声明真实。

不直接扩展任务成功阈值或连续误差，不根据本轮性能结果延后领域验证。当前下一项工作应是获取并审核真实领域事件定义和校准/端到端观测；在此之前保持模型领域状态pending，不仅凭合成对照改变生产精度公式。

## 复现

仓库根目录运行，协议及输出路径均须不存在：

```powershell
New-Item -ItemType Directory -Force tmp | Out-Null
.\.venv\Scripts\python.exe -B -m unittest tests.test_accuracy_validation tests.test_joint_candidates -v > tmp/my-accuracy-tests.log 2>&1
.\.venv\Scripts\python.exe -B -m workflow_tools.validate_accuracy_model --freeze-protocol generated/task-flow/my-accuracy-protocol.json
.\.venv\Scripts\python.exe -B -m workflow_tools.validate_accuracy_model --protocol generated/task-flow/my-accuracy-protocol.json --output-dir generated/task-flow/my-accuracy-validation
.\.venv\Scripts\python.exe -B -m workflow_tools.report_accuracy_validation --source generated/task-flow/my-accuracy-validation --output-dir generated/task-flow/my-accuracy-report --test-log tmp/my-accuracy-tests.log
```

第三条命令核对冻结源码摘要，随后执行全部实验；第四条独立重放所有故障/标签并从CSV复算全部种子和合并统计。图表用标准Matplotlib生成独立SVG，Python版本与固定种子保留在协议，压缩文件mtime固定为0便于字节复现。
