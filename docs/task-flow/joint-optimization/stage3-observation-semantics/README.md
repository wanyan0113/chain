# 观测接口统计语义审查

审查对象：`tfdo-observation-intake-1.0`及已接通的采集路径。结论：**现有限定范围内有条件通过，5项统计语义扩展缺口未关闭；真实领域精度仍pending。** 本轮是用独立参考核对器进行的软件审查，不是第三方人员或领域专家的独立复核。

生产公式、旧数据协议、历史实验、旧manifest及原最优性等级没有修改。43项相关测试通过，含7项新增参考核对测试；11组反例/正例探针复现预期行为。探针断言通过不等于这5项缺口已修复，也不等于精度模型通过。

## 已确认的正确行为

- 两个decide实例以s2、s3分别统计：校准正确率分别为1/4与3/4，没有按类型合并。
- 校准环节分母可以不同，反例得到4/3/4/4，未用整条链样本数替代。
- 已记录的missing、not_executed和缺环节会阻塞统计推断，不补失败或补成功。
- 最后输出的实测率不是环节标签或精度的乘积；预测乘积与观测率保持分开。
- 没有声明直接标签传递时，不把恢复次数当作因果纠错；重复执行同一实例被拒绝，未变成更多独立样本。
- 3环节与4环节流程分别评价，不生成一个掩盖差异的平均误差。

## 正式发现

| 编号 | 发现与证据 | 对现有结论的影响 | 后续要求 |
| --- | --- | --- | --- |
| OBS-SEM-001 | 没有独立入组登记表。4名登记样本中整条删除1名记录后，v1只看到3名；若仍满足最低覆盖，不能发现整条样本缺失 | 高优先级覆盖保证缺口。v1无法单独保证预定义队列分母完整 | 增加入组/分配登记，逐样本核对期望环节和终点覆盖 |
| OBS-SEM-002 | 缺一个中间环节时，独立参考的各环节可评价数为4/3/4/4；v1尚未逐环节报告评估集分母，诊断按3名完整案例计算 | 现有阻塞保护有效，但描述性统计不足；校准分母正确不能替代评估分母 | 同时报登记、进入/执行、已记录、可评价、正确与缺失数量 |
| OBS-SEM-003 | 同一类别值的两个不同样本中，错误输入来源仍可满足input_label与前序输出值相等 | 标签一致性不等于数据来源一致性 | 增加输入/输出引用及来源观测关联，检查样本、执行、环节与版本 |
| OBS-SEM-004 | v1终点是最后分类输出对共同gold_label的正确率；另一独立任务完成事件可有不同结果，不能直接复用该率 | 这是范围扩展需求，不是v1分类算术错误。当前不支持任意任务最终效果的独立终点表 | 预定义最终事件、评价方法、真值与证据；独立保存终点评价 |
| OBS-SEM-005 | missing/not_executed没有原因字段，也不能区分未进入、未执行、记录丢失、标签不可评价；v1只支持每实例一次观测 | 不足以解释失访或重试机制；旧接口会拒绝直接增加新列或同实例多条重试记录 | 版本化状态与原因，区分逻辑实例和执行尝试，冻结重试取值规则 |

最明确的分母例子：仅s2缺记录时，s4本身仍有4名可评价、3名正确，描述率为3/4；完整案例子集剩3名，其中2名终点正确，描述率为2/3。两者统计对象不同。v1已阻塞该批模型推断，因此没有将2/3作为合格的全队列估计；下一版必须把两种集合及缺失覆盖讲清楚。

独立终点探针的0.75与0.25对应不同事件：前者是分类标签正确，后者是另定义的合成任务完成标准。这个差异证明需要明确终点定义，不证明v1在其共同分类标签定义下算错。

## 当前适用范围

v1可用于共同二元标签、已记录完整案例及单次环节观测的有限分析；其ready_for_statistical_assessment只表示满足当前协议和可见数据检查，不证明登记队列无漏失、引用真实或领域标签可信。正式预登记队列或不同于分类输出的任务终点验收，应先补齐上述契约。

前序错误后输出变正确只叫“观测到恢复”。有纠错机制/无纠错机制的确认性比较应按预定义机制或实验组分组，不按结果出现后才挑选“发生纠错的样本”作因果比较。类型分组须取绑定元数据中的activity_type，不能把activity_id字符串当类型；本轮fixture特意让两个活动ID相同，仅验证实例不合并。

## 证据与复现
