# v2观测契约草案与验收矩阵（尚未实现）

目的：补齐入组队列、环节分母、实际输入来源和独立终点的可解释性。保留sequential_product_v2作为待验预测，不增加复杂统计或改变生产评分；v1文件及已有hash继续保留。

## 数据对象分开保存

| 对象 | 关键字段及定义 |
| --- | --- |
| 入组与分配登记 | sample_id、cluster_id、flow_id/candidate_id、split、预定义纳入条件、入组时间、分层、期望stage_instance_id列表、终点评价资格。未纳入需原因和规则版本 |
| 环节执行观测 | observation_id、sample_id、execution_run_id、stage_instance_id、attempt_id、activity_id/version、artifact_id/version、输入/输出引用、实际输入来源观测ID、执行/记录/可评价状态 |
| 环节评价 | stage_outcome、stage_target_id、evaluation_method_id/version、真值/参考证据、评价时间。正确、错误、不可评价分开 |
| 独立终点评价 | 每个任务执行一条final_outcome、endpoint_target_id、终点真值/证据、评价方法/版本和时间；不在每个环节重复计入 |
| 方法与分组登记 | 标签和事件定义、纳入/排除规则、拒判口径、重试选取规则、缺失处理、流程长度/类型序列/版本/纠错机制实验组、容差与置信政策 |

可使用受控存储引用或不可逆标识，不强制将原始内容放入CSV。input_reference与output_reference需能在研究权限内对应到同一内容；额外记录input_source_observation_id以核对它来自同一执行/样本的哪次输出。标识一致只支持来源记录的自洽，真实性仍需审核，程序不主动读取外部内容。

固定名单可预先冻结；连续入组可采用预定义规则加逐样本入组记录。不能通过完全不记录样本或事后删除资格改变分母。入组登记不是要求采集前已知道所有真实标签。

## 分母与状态

每个stage_instance_id分别报告：n_expected、n_recorded、n_executed、n_evaluable、n_correct、各种缺失/未执行/未进入原因。描述性环节正确率为n_correct/n_evaluable，同时展示它覆盖了多少预定义样本；n_evaluable为0时为null。

不能把“未进入后续环节”自动记成该环节错误；也不能把它从端到端队列中静默删除。若预定义终点规则认定上游终止即任务失败，应由有方法和证据的终点评价记录失败；如果终点未知则记录未知并阻塞确认性结论，不做默认填充。

终点分别展示预定义可纳入数、已评价数、成功数及未评价原因。缺失终点时可展示明确标注的已评价子集描述率，但当前保守验收策略不将其冒充全队列无偏估计或通过结论。

stage_outcome评价环节本身的目标，不一定与final_outcome是同一事件。共同分类目标可通过独立真值与最后实际输出产生终点结论；独立不意味着必须另手填一个无法核查的布尔值。不同任务效果需要明确不同的终点定义和证据，不能把分类gold_label自动改名为实际效果标签。

缺失原因至少区分：未到达该环节、计划未执行、执行失败、输出记录丢失、缺少真值、无法评价。还应区分明确拒判这个已执行结果。原因不能为空时的规则应在协议冻结，不通过随意增加一个文本字段规避检查。

逻辑上的重复decide使用不同stage_instance_id；同一实例的再次尝试使用attempt_id。first_attempt或预定截止前final_attempt等取值规则需在试验前冻结，不能根据正确答案选“最好一次”。当前v1拒绝同一实例多条记录，这个保护继续作为旧版本行为保留。

## 关联与分组

直接前序依赖需核对实际输入/输出引用、来源观测、样本、执行及阶段顺序，不能只比较类别值。允许的非相邻或其他输入来源应预先声明，不把链的画图顺序当作统计依赖证明。

3/4环节、重复decide、法器/版本、预定义纠错机制分别分组；不能只报总体平均误差。activity_type从所选设计绑定取得，activity_id保留活动身份，二者不可替代。observed_recovery只作描述；按结果挑选“发生恢复者”不能证明纠错机制的因果收益。

不同组的人群与任务难度可能不同，分组率不同不自动代表增加环节或换法器的效果。本次不引入复杂因果/相关统计；无法支持的设计继续阻塞或明确限制结论。

## 下一版验收矩阵

| 反例/正例 | 预期行为 |
| --- | --- |
| 两个同类型实例的正确数不同 | 分别统计，不按类型合并 |
| 中间环节缺1条，末环节仍有完整记录 | 各阶段分母独立，完整案例与末环节子集明确区分 |
| 一个登记样本全链无记录 | 能从登记表发现，列出缺失，阻塞完整队列结论 |
| 某样本按预定义规则不纳入 | 保留资格规则及原因，不进入相应分母，不删除审计记录 |
| 同类别值来自另一个样本 | 来源关联检查失败，不能因标签值相同通过 |
| 顺序相邻但没有直接输入依赖 | 不推断串行误差传播或因果纠错 |
| 最后类别正确但任务效果失败 | 按各自事件保留两种结果，不能覆盖独立终点 |
| 终点评价缺失 | 不补失败或成功，不把已评价子集当全队列 |
| 同一环节重试两次 | 保留attempt_id并执行预定义取值规则，不增加独立样本量 |
| 法器版本、输入引用或登记队列冻结后变化 | 新研究/新快照或明确阻塞，不复用旧hash |
| 合成数据或统计等效结果 | 不自动升级真实领域有效性，仍pending |

这些要求需要版本化的新模板、校验器、来源绑定和研究锁；不能仅给v1 CSV追加字段后继续沿用旧解释。评分公式及旧最优性等级在本次方案中保持不变。
