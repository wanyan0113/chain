## 验收边界

- 本阶段实现数据模型与生成侧状态语义，不生成候选流程，不声称覆盖率、无解或最优性。
- 结构合法的活动序列可能语义不可执行；validate_sequence不检查最终目标，不能称为独立验证。
- 显式静态证据的来源字符串和摘要由输入提供，组件只校验结构与一致性，不证明事实真伪。
- 能力URI全部标记unmapped，尚未接入原本体能力匹配。
- 数值只支持整数；派生规则只支持无循环、每落地事实一条布尔规则。
- 旧代码、本体、评分、实验结果及FDNA桥接均未修改；实际适配与资源落实继续属于后续阶段。
