## 本次完成范围

完成第一阶段的需求分析、代码盘点、总体架构、接口字段草案、语义决策、通用业务示例和后续阶段验收安排。接口草案标记为 `task-flow-draft-0.1`，正式 JSON Schema、运行模块和 CLI 在后续阶段实现。

本阶段没有实现自动规划、独立运行验证器、连续参数优化或多装备协同调度。示例的阶段数由人工推演得到，用于第二阶段检验数据表达；不作为自动生成能力的证明。提交标题按用户要求使用“尝试多链共享一个资源”，不据此宣称新增资源共享算法。

## 实施原则

- 先固定数据契约与语义，再实现生成与验证算法。
- 首版处理有限对象和参数域下的有界顺序流程。
- 小规模独立穷举只用于检查相应测试实例和边界内的覆盖，不证明所有输入均正确。
- 任务事实到能力、能力到资源的现有推理可以复用；通用流程经显式适配后才能进入旧接口。
- 历史实验、FDNA公式及旧设计引擎的语义保持独立，后续以回归检查防止改变。
