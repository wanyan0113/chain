# 训练基础样本成组重采样后重拟合：固定方案

2026-11-23，在本步计算前登记`data/fdna/training_refit_protocol.json`。

此前04与07仅重采样留出基准，所有模型参数冻结。本步改为从原90个训练基础样本中有放回抽取90次，固定种子2026112308，重复50次。同一次抽样同时用于3种环境及基础式/自由δ模型；原30个留出基础样本保持原样，不进入抽样或求解。
50次为预先登记的有限敏感性诊断，不以其极端分位数声明置信区间，也不因结果不合意增加重复次数。

## 求解设置与隔离

保留原6个起点、1500求解上限、求解器种子及δ边界；每次重新从原中性与固定种子随机起点求解，不以上一次估计或原参数热启动。
固定起点机制，使本步主要观察训练构成改变的结果，而不是额外混入另换起点种子。原有多初值跨度仍逐次记录；本步不能穷尽求解器不确定性。
首次用完整原训练/留出复跑作为控制，与冻结结果核对参数和逐条预测；控制不计入50次重采样。

每次抽样按基础样本保留全部环境和节点，重复观测赋予新的sample_id，base_case_id保留原身份。重复90条不等于90个独立训练基础样本，逐次记录实际不同基础样本数。留出与训练不交叉，不补0、不裁剪预测，不重新生成SE或修改拓扑。

## 输出

- 逐次保存抽样索引、不同训练基础样本数、数据/设置摘要、状态、参数、局部秩、触界、不活跃参数、近优跨度和全部6起点的求解结果。
- 同一固定留出数据上记录局部/递推预测及误差。失败和受阻状态保留，不把它们悄悄从分母删除。
- 参数及预测误差分布仅报最小值、中位数、最大值，并报告有效记录数/预定50次。参数范围不是置信区间；尤其局部秩不足、补偿、边界和局部解存在时，不能将波动小解释为参数真实或唯一。
- 独立标量核对每个起点的训练RMSE、成功模型的留出预测和汇总范围。逐次文件便于溯源，不保存无必要的重复完整SE快照。

原公式与参数冻结包保持不变，本步在独立目录保存重新估计的实验模型，不能覆盖正式参数。已有留出结果此前被查看，本步不选择方法、不当成新独立泛化测试。
