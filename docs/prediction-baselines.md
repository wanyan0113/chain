# 同条件简单预测基线：固定方案

2026-11-23，在计算基线结果之前固定以下方案。配置为`data/fdna/prediction_baseline_protocol.json`。

## 目标与数据

读取已经冻结且校验通过的06场景，保留360条合成网络观测、三个环境分组和90组训练/30组留出的基础样本划分。
原基础式与自由δ参数全部冻结，不重新求解FDNA，不修改SE，不调整边或δ边界。
此次是在已有留出结果被查看之后追加的描述性对照，不是未使用过的最终测试，不能据此选择方法后再宣称独立泛化优势。

## 两种基线

- 训练均值：逐环境、逐接受节点，仅用完整局部训练记录的目标均值预测；不使用供给特征。
- 普通线性回归：相同训练记录，以拓扑给定的供给SE为特征，带截距，用NumPy最小二乘求解；不调参、不正则化、不选择特征。

线性设计矩阵秩不足时保留最小范数解并标记，不能解释其系数唯一。记录样本数、训练记录编号、矩阵秩、参数维度、系数和运行版本。
两种基线使用与FDNA相同的局部完整训练记录；训练均值虽然不需要特征，也不额外获得FDNA因缺失供给而排除的训练目标。

## 公平比较

局部预测使用同一记录的供给观测。整网递推只获得相同外部根输入，中间节点使用各自模型预测；不读取中间节点观测真值或FDNA预测。
预测不裁剪，分别记录输出越界、缺失及受阻。分别报告训练/留出、局部/递推、中间/末端节点的RMSE、MAE和覆盖数。
除各方法可用记录外，另在所有方法均可评估的共同记录集合计算指标；缺失或失败不通过改变评价集合隐瞒。

基础样本划分先复核无泄漏。输入摘要须匹配冻结报告；按原参数重算FDNA预测并与冻结逐条预测核对。
基线没有α/β语义，只比较预测，不比较依赖参数准确性，不自动运行退化分析或声称真实因果。
