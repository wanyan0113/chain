# 冻结模型：全留出基准传播补充

[三张图及配套说明](结果说明.md) · [270行响应摘要CSV](多基准响应摘要.csv) · [运行审计](运行审计.json) · [独立标量核验](独立标量复核.json)

本步把每个模型任务的首条留出基准扩展为全部30条，固定原参数、SE与五档保留比例，不重新拟合。共180个任务×基准、8100条响应；原270条响应最大差0。所有响应无输出越界，3819条目标直接供给外推，约47.15%。输出在SE范围内不证明推演已获训练覆盖。

图2明确区分基准异质性与均值构成稳定性，左右共用横轴。例如env_0/基础式的A1置零使F1平均减少42.8365；具体响应P10-P90为[18.3747,68.6315]，均值重采样中央95%经验范围为[35.8683,49.6666]。统计对象不同，均不包括参数不确定性。

117项相关测试通过；独立核验32400个响应值、56700个非后代值、540000个重采样均值及2160个摘要值，最大差约4.26e-14。

这仅推进第5项稳定性的一部分，不包括训练重采样后重拟合、α/β/δ区间、求解器变化或真实因果；也不是替代拓扑实验。完整逐条数据保存在本地07核验包，此处提供可直接阅读的图表与摘要，不重复上传全部事件或逐次数据。

方法与复跑说明见[固定方案](../propagation-stability.md)，此前的六图汇报见[优化汇报快照](../optimization-report/README.md)。本目录manifest记录快照精确字节，文本统一为LF以便跨平台核对。
