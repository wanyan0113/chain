# 重估实验模型的相对退化传播：固定方案

2026-11-23，在运行之前登记`data/fdna/refit_propagation_protocol.json`。先复核08包50轮训练成组重拟合，再将这些已估计的实验模型用于同一原30个留出基准。没有额外拟合、SE生成、改边或修改原正式参数。

## 问题与对照

08检查了参数和预测如何随训练构成变化；07只传播冻结的原模型。本步检查08重新估计的参数用于原五档比例退化时，下游响应如何变化。
外部根观测保持不变，中间节点仅使用各模型自己的递推预测。干预值为该模型自己的节点基准值乘保留比例，暂停其入边、重算后代；不读取中间节点观测真值。

必须注意：不同模型的中间节点基准可能不同，所以相同比例不一定对应相同绝对强制值。本步是“相对退化情景的模型敏感性”，不能称为隔离单一参数后的固定绝对干预效应。
先用08完整训练控制参数作回放，与07全部8100条冻结响应逐条核对，再进行50轮实验模型回放。向量化计算另用独立标量公式验证，不运行新的求解器。

## 面板与统计

按每个模型任务×干预节点×可达目标×比例，保存每个固定基准的预测、强制值、减少量和范围标记。单个拟合任务只要有接受节点未成功，该任务明确不可用，不用原参数替换。基准缺失、非有限或被干预节点基准超[0,100]时保留不可用标记；模型均值必须覆盖同一全部30基准，否则不纳入均值范围比较，分母仍是预定50轮。

每轮先在同一30个基准上求平均减少量，然后对50轮均值报告最小、中位、最大，与原模型均值并列。它与07中“固定模型的基准异质性”“固定模型的均值抽样构成”不同，不将1500个模型×基准组合当作1500个独立训练实验。
记录输出越界和目标直接供给超当轮训练范围；只检查目标直接供给，不宣称整条路径覆盖。

图中只展示有限实验范围，不称置信区间、显著性、全局唯一或真实因果。固定示例为env_0/自由δ/B1置零→F1，参数与传播的散点只作同批模型关联描述，不单独归因于某个β。不得按新结果选择示例或调整边界。
