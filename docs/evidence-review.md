# 一个命令复核优化成果

新增主CLI入口`python -B -m fdna review-results`，把已有成果的检查和阅读入口集中起来。它不拟合模型、不生成SE、不重新测时、不改变正式图或参数。用于汇报前检查材料是否变化，以及在本地原始产物齐备时重新执行独立复核。

## 两种模式

| 模式 | 本次实际做什么 | 所需文件 |
| --- | --- | --- |
| `published`，默认 | 对7个发布成果包95个文件检查精确字节清单，检查两份说明文档版本，生成成果与进度索引 | 仓库内docs与目录配置；不需要原始generated |
| `full` | 先做上述检查，再顺序执行10项本次独立复核；保留失败并继续检查其他任务 | 显式指定包含原06及相关generated成果的项目根目录 |

从当前`.publish/fdna-bridge`工作树运行，输出目录须不存在或为空；本次最后执行保存在13/最终核验，重复运行请改用新目录：

```powershell
# 快速检查已发布材料，不把历史核验记录当成本次数值重算
& '..\..\.venv\Scripts\python.exe' -B -m fdna review-results --mode published --output-dir '..\..\generated\关于优化\13_统一复核入口\最终核验\发布材料检查'

# 有完整本地来源时，实际重新执行数值核验
& '..\..\.venv\Scripts\python.exe' -B -m fdna review-results --mode full --project-root '..\..' --output-dir '..\..\generated\关于优化\13_统一复核入口\最终核验\完整数值复核'
```

每次运行生成`review_report.json`、`成果复核与阅读入口.md`、`目录版本.json`和精确字节manifest。Markdown集中链接原图文报告、方法边界和卡片使用说明，列出当前范围及未完成事项。退出码0为所请求模式全部通过，1为检查失败，2为请求无效；后两种均不能当成通过。

## full的十项任务

06原场景94文件完整性、六图与来源CSV核对、简单预测基线、冻结预测稳定性、冻结传播、训练重拟合、重估传播、分支启用、依赖消融、性能计时记录及全量标量回归。均调用已有独立脚本的verify函数，模块名单固定，不从外部配置执行任意脚本。

来源缺失不会跳过后标为通过，不会静默降级成published。单项失败保留类型与信息，其余任务继续；每项分别记录脚本是否已调用。全部来源缺失时，脚本调用数为0、数值执行与完成标记均为false，不把请求full当成实际完成重算。已有独立脚本使用断言，因此full拒绝`python -O/-OO`；published自身的字节检查不依赖断言。输出不能写进代码、已发布成果或旧来源包内部，也不覆盖非空目录。

性能任务核对既有5轮计时算术和完整回放数值，不是重新测时；重复检查的计数不相加成新的独立实验数量。源包完整性与数值重算也分别标记，避免把材料字节相同当成模型实际有效。
