# 重估模型从训练到退化的分支启用诊断

这是优化优先级第1、2、5项的解释与审计补充，扩展已有`fdna.branch_explanation`对冻结模型的分支解释；不重复宣称首次实现分支诊断，不增加拟合、不选择模型或修改原正式结果。

## 固定方案

运行前登记`data/fdna/refit_branch_protocol.json`，复用08全部50轮实验模型、相应90次成组训练抽样和09全部30基准×五档比例。只验证当前单供给结构；多输入模型明确拒绝，避免把COD最小候选的语义直接套用。

当前公式为`SE=min(100−α(100−x),x+β)+δ`。在加δ之前按1e-8容差比较SOD/COD，近并列保留双候选。容差沿用已有冻结分支解释；08的参数灵敏度另使用其登记容差，不混称两者完全相同的诊断定义。

严格训练不活跃定义为：在该轮全部训练供给观测中，仅SOD限制，没有COD或近并列。传播中另记同模型递推基准到干预后的限制分支，分开训练供给与递推供给，禁止读取留出内部真值。β的0/1导数仅在单供给、固定输入及其他参数、唯一分支的局部意义下成立；近并列不选唯一导数，大退化响应不按局部导数线性外推。

## 已运行结果

[图表与文字说明](refit-branch-report/结果说明.md)展示1588/1800次拟合训练β严格不活跃。9009条响应满足训练β不活跃且传播COD限制，其中8789条从同模型基准SOD转来，220条基准已是COD，0条来自基准近并列。这9009条均存在目标直接供给外推，不作为真实有效性证据。

146次局部拟合在本批递推/干预情景中至少一次出现这种启用；这个分母与响应记录数不同。66条近并列保留双候选。147项相关测试通过；独立标量核验162000条训练输入与405000条响应、13500行模型条件、270行摘要，数值差0。

## 复跑与核验

从`.publish/fdna-bridge`运行；输出目录须不存在或为空，核验输出文件也不能已存在：

```powershell
& '..\..\.venv\Scripts\python.exe' -B -m fdna.refit_branches --propagation-dir '..\..\generated\关于优化\09_重估模型传播敏感性' --protocol data/fdna/refit_branch_protocol.json --output-dir '..\..\generated\关于优化\10_重估模型分支启用诊断_核验版'

& '..\..\.venv\Scripts\python.exe' -B workflow_tools/publish_refit_branches.py --source '..\..\generated\关于优化\10_重估模型分支启用诊断_核验版' --destination docs/refit-branch-report
```

独立脚本不调用生产分支分类器，从原根观测用标量公式重算网络，对比每条分支代码、目标预测、训练计数及三张CSV。来源包哈希、报告/数组指纹和精确字节清单保持追溯；迁移路径后仍须保留源文件摘要。GitHub图文快照可直接阅读，不替代本地来源包的重拟合复现。

这是有限模型内机制证据，不提供参数或传播置信区间，不证明真实因果、物理意义、FDNA优于OLS或基础式比自由δ更可靠。拓扑T-Frozen/T-Refit及真实数据验证未开展。
