# 温和版运行说明

本分支为“改成温和的”。在已发布的FDNA网络工作流基础上加入温和西幻命名的模拟器、命名对照表，以及三个案例和组网网页。

桌面工程中的fdna_workflow/fdna在此仓库对应根目录fdna，沿用已有工作流发布布局。没有将桌面工程中原有的目录删除操作加入提交。

安装依赖：

```powershell
python -m venv .venv
.\.venv\Scripts\python.exe -m pip install -r requirements-workflow.txt
```

启动网页：

```powershell
.\.venv\Scripts\python.exe -B generated/weekly-report-40963d3/demo_server.py --port 8876
```

打开 http://127.0.0.1:8876/ ，组网页为 http://127.0.0.1:8876/network 。网页使用包内固定快照及示例输入，不上传历史运行结果、虚拟环境或Word报告。来源图表作为原文参考保留，不代表图中的原文名称已被修改。

运行模拟器：

```powershell
.\.venv\Scripts\python.exe -B fdna_sim/run_demo.py --mode clean --pure --runs 600 --no_attunement
```

模拟器新参数为--no_attunement、--attunement_repeats，输出使用温和字段名。默认完整模拟会执行多次参数优化，耗时高于网页示例。模型公式、数值、单位与改名前保持一致；原文数据与人工生成数据的边界见命名对照表。
