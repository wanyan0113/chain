# 冻结模型的全留出基准退化响应：固定方案

2026-11-23，在运行本步之前固定配置`data/fdna/propagation_stability_protocol.json`。

原06标准退化分析只使用每个拟合任务按sample_id排序的首条留出基准。本步保留原36次FDNA拟合参数、拓扑和全部SE，扩展至每个任务全部30条留出基准，不按响应或误差挑选。
保留原0、0.25、0.5、0.75、1五档保留比例；强制值为被干预节点的模型基准值乘比例。中间节点暂停入边方程，其余根输入和机制保持不变；只统计可达后代，节点自身不算后代。此为标准观测根输入的模型内情景，不是05共同来源H情景。

## 两种变化分别报告

1. 基准异质性：30条具体留出基准下的SE减少量，记录均值、最小/最大、P10/P90、零响应、越界和目标直接供给外推。它描述不同基准，不是参数区间。
2. 均值响应的样本构成稳定性：原样复用04包2000次基础样本成组抽样索引，同一次抽样联合保留环境、模型、干预节点、目标和比例。统计平均SE减少量的2.5%、50%、97.5%经验分位数。不能把单基准P10/P90和均值重采样范围混为一谈。

全留出面板缺失或受阻则明确拒绝，不补0或默默删样本。输出保留原始预测，不裁剪；输入范围外的情景标记为外推。外推字段只检查目标节点直接供给范围，不表示整条传播路径已验证。
与06首条基准的既有270条响应逐条对照，并记录单调性、保留比例1应为零效应、非后代不变及核心干预公式交叉核验。

## 分析边界

这是第5项稳定性优化的另一个限定子项：冻结模型的基准异质性与均值响应构成稳定性。没有训练重采样后重拟合，不覆盖α/β/δ不确定性、求解器变化或真实干预因果，也不构成参数置信区间。不会将它登记为全部传播不确定性已解决。
不改变结构，不属于T-Frozen/T-Refit拓扑替代实验；不与基线OLS的预测误差排名混为一谈。
