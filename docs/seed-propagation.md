# 求解起点种子模型的相对退化传播敏感性

本步推进优化清单第5项：17号实验固定数据、改变求解起点种子，已检查普通预测；本步将其五组已估计模型用于相同退化面板，补充传播结果对起点种子的敏感性。没有重新拟合、生成SE、选择种子或改动正式图。

计算前登记`data/fdna/seed_propagation_protocol.json`：五个种子、六个环境×模型任务、原30个留出基础样本、九组可达关系、五档保留比例，共40500条响应。模型只读取原外部根输入；强制节点值为该模型自身基准×保留比例，暂停其入边并重算后代。比例非零时不同模型的绝对干预值可能不同，不能解释成固定绝对干预或隔离β的因果效应。

先独立复核17号模型，再将原种子8100条响应与07冻结传播逐条比较。失败模型不替换为原参数；均值须覆盖相同全部30个基准，分母保留预定五模型。目标供给外推和输出越界单独记录，未裁剪。

预先固定两个示例：env_0/自由δ/B1置零→F1沿用09；env_0.3/自由δ/B3置零→F3依据17号已观察的β跨度选定，发生在本轮传播运行之前。后者是针对已有发现的机制追查，不能作为独立确认性测试。统计每个种子的训练β不活跃标记及置零后唯一COD限制的基准条数；该标记沿用局部平滑敏感度诊断，不是全局不可辨识证明。

## 运行与核验

从`.publish/fdna-bridge`运行，选择新的空目录保留首次结果：

```powershell
& '..\..\.venv\Scripts\python.exe' -B -m fdna.seed_propagation --seed-dir '..\..\generated\关于优化\17_求解起点种子敏感性' --frozen-report '..\..\generated\关于优化\07_冻结模型多基准传播_核验版\propagation_report.json' --protocol data/fdna/seed_propagation_protocol.json --output-dir '..\..\generated\关于优化\18_求解种子模型传播敏感性_复跑'
& '..\..\.venv\Scripts\python.exe' -B -m workflow_tools.verify_seed_propagation --report-dir '..\..\generated\关于优化\18_求解种子模型传播敏感性_复跑'
```

独立脚本使用标量DAG公式重算全部响应、非后代不变性、越界/外推、原种子控制、270行条件摘要、1350行种子均值与10行固定示例，不调用生产传播实现。原06包和17号来源前后保留字节校验。输出为两张PNG/SVG、完整响应NPZ、JSON、CSV；结果与文字说明保存在`generated/关于优化/18_求解种子模型传播敏感性`。[公开图文与核验快照](seed-propagation-report/README.md)保留完整数组，但独立复核仍需要本地06/07/17来源。

233项相关测试通过。本步覆盖有限起点种子下的模型内传播，未覆盖其他求解器、PCA或更多起点，也不是有效置信区间、真实故障干预验证或新泛化测试。第5项仍部分完成。原七包统一目录保持原登记，本成果通过上述独立入口复核。
