## 单位：原值保存与计算表示分开

| 原文 | 原值层 | 对应主本体／转换要求 |
|---|---|---|
| 距离 n mile | 保留原海里数值 | `*Nm`字段保持海里，不换成米；1海里=1852米只在明确需要时换算 |
| 高度 ft | 保留原英尺数值 | `*Ft`字段保持英尺，不把海拔改成离地高度 |
| 速度 kn | 保留原节数值 | `*Kn`字段保持节，不改成米/秒；目标速度与法术飞行速度分开 |
| 命中率 % | JSON保留95、85等百分数 | 当前 `hitProbability` 声明0—1口径，输入计算图时需明确95%=0.95；不能把95直接当0—1概率。原值仍保留95% |
| 侦察精度90、80等 | 保留表8原数，原表未标单位 | 表13按90%、80%使用；若写 `detectionPrecision`，须记录按百分比解释并除100，不由代码静默猜测 |
| 度分秒经纬度 | 保留原列名与N/E原串 | `longitudeDeg`／`latitudeDeg`要求decimal；核实方向后才能用度+分/60+秒/3600转十进制度，并保留原串 |
| 毁伤值／抗毁值 | 原样保留 | 原表未说明物理量纲，不编造单位，也不自动当成本或元素抗性系数 |

“只改名字”应指物理含义和量值不变。95%与0.95量值相同但数值写法不同；若要求连数字字面值也保留，应在来源层保留95及%，计算层显式转换。不能同时要求保留数字95、又把它填进0—1口径。
