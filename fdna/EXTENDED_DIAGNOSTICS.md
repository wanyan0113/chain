# 新实验组冻结结果深入诊断

本阶段补齐第四次修订补充版第8、9及13.3节所要求的新组残差、参数诊断和供给质量统计。覆盖变化C/M/E、过程σ=2及交互γ=0.05/0.15/0.30五组，读取第10至13阶段已有结果，不重新拟合，不生成样本，不改变机制或δ界限。

## 核验与解释

复核1800次局部拟合、900000条局部/整网预测和14400组指标，另以每组首尾记录进行1200次核心网络计算对照。逐次核验训练/验证残差，保留局部与整网MSE分解中的交叉项。上述条目包含模型、节点和配对噪声，不能当作独立实验次数。

沿用已冻结的诊断容差：训练RMSE差≤1e−6且收敛的起点才进入近等起点分析；训练与验证预测变化均≤1e−6，才认定为当前样本上的近似等价。预设归一化参数扰动不超过0.1，并服从实际参数边界。不利用验证结果选择起点、方向或步长。

参数零方向区分不活跃参数、涉及δ的补偿方向及其他零方向。确认δ路径时额外检查δ实际变化超过数值容差，不能只依据方向标签。没有找到某类路径不证明它不存在，有限样本等价不证明全局等价。

供给质量按每个干净网络记录一次，再按重复、训练/验证、节点统计：实际供给范围、Pearson相关、各供给成为唯一/并列最低输入的频率、最低输入低于20/40的比例、目标低于最低输入的比例、结构下界、生成截断。20/40是预先设定的描述阈值，不进入生成或优化，不是原文退化标准。常数输入相关保留未定义；不以0替代。

生成截断和观测截断分别统计。含δ预测保持不裁剪，按精确代数条件核验低于0和超过100。实际干净输入上的质量下界与基础式局部拟合逐项对照，不将其用于含δ或整网误差。

## 文件入口与复跑

- `data/fdna/generation_extended_diagnostics.json`登记四个来源、五个组、预设例子、容差和低输入阈值。
- `fdna/generation_extended_diagnostics.py`调用已有冻结诊断器并补供给质量统计。
- `fdna/generation_extended_diagnostics_report.py`汇总参数路径、残差、质量数据及7张汇报图。
- `tests/test_fdna_extended_diagnostics.py`验证不拟合、质量口径、噪声隔离、常数相关、重复拒绝以及δ路径的实际变化。

从第10至13包恢复配置所列的generation、base及comparison文件，再在工程根目录运行；输出目录须为空。

```powershell
python -B -m fdna.generation_extended_diagnostics --config data/fdna/generation_extended_diagnostics.json --output-dir generated/stage2-extended-diagnostics
```

每个来源子目录保存完整残差、近等起点和参数扰动CSV；summary目录保存汇报图、跨来源表格及实际δ补偿路径。它们用于解释已有模型的表现，不代表参数识别、表达限制或输出范围问题已经解决。下一步仍需其他生成系数的系统敏感性、正式多输入和11节点18边独立生成拟合。
