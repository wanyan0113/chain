# 装备网络到能力依赖网络：小范围研究原型

V1.0冻结标签 `fdna-v1.0.0` 不变。本分支新增独立适配器，不改FDNA正向式、优化器或参数边界。

入口是上游保存的 `design_report.json` 与人工登记的 `mapping.json`。首版只支持 `single_unit_per_role` 计划及单链范围，实例按主体、功能和场景显式命名。链是否已选、角色主体是否一致、范围是否完整先于拟合校验；候选链、资源共享关系与链排名分数不直接进入SE网络。

活动输出与下游输入的产品标识匹配可产生待审候选。只有状态为 `approved_assumption`、直接设备连接成立且输入输出确实匹配的候选才导出。该状态表示研究者批准的模拟工作假设，不表示已经通过实证验证。通信心跳待审、传递边待审、原始设备证据、被排除的链均保留在侧车文件。反馈环报错，不能自动删边凑DAG。

## 复跑

在本仓库根目录、安装V1依赖后运行，输出目录须不存在或为空：

```powershell
python -m fdna.bridge_demo --config-dir data/fdna/bridge --output-dir generated/bridge-demo
python -m unittest discover -s tests -p test_equipment_bridge.py -v
```

输入全部冻结在 `data/fdna/bridge/`，包括原始完整上游报告、映射审查、节点机制、实验与拟合配置。演示生成120组基础数据，90训练/30留出，σ=0/2配对，训练划分按基础样本冻结。供给输入使用干净SE，接受目标使用观测SE；真实数据输入误差不在此演示中建模。

这是单根链，使用基于现有 `NetworkGenerator` 的简单均匀采样器，不修改原有要求多根的联合采样器，也不为迁就接口伪造第二个根。当前采样器拒绝非零过程波动、交互项或多次重复配置。

## 预期结果与限制

本例独立机制使输出按固定条件系数逐层衰减。单输入基础FDNA在α∈[0,1]、β∈[0,100]时输出不小于输入，因此无法精确表示该衰减。自由δ可能改善误差，但触及−10边界且可能出现负预测。报告保留误差、边界、局部秩不足、外推与越界，不用裁剪隐藏问题。

本例用于验证两套接口能够衔接，并展示方法边界；不用于唯一恢复αβ、不建立参数重要性排名、不声称复现两篇论文的真实案例。尚不支持自动解决跨任务共享状态、多装备活动计划、资源竞争、反馈回路或自动学习真实拓扑。

`write_bundle`的原清单覆盖表格与JSON；演示完成后另写 `全部产物校验.json`，覆盖新增图像在内的全部已有产物，不含该校验文件本身。
