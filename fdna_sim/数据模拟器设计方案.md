## 0. 一句话定位

**它不是"编数据的脚本"，而是一个"可控反事实实验台"**：在给定能力依赖网络（11 节点 / 18 边）上，

1. 用 7 个实验变量驱动源节点指标 → 归一化为 SE；
2. 用"真值依赖结构"聚合出内生节点 SE，**同时注入 FDNA 结构刻画不到的因素**；
3. 反过来用论文的 SoD/CoD 模型去拟合这批数据，检查**参数能否被还原、残差从哪来**；
4. 通过开关式消融，把论文"拟合效果一般"这一结论**从定性猜测变成可定量归因**。

因此它同时是：论文的**复现工具**、方法的**压力测试床**、后续改进的**基线发生器**。

## 2. 模拟器要回答的三个问题

| 编号 | 问题 | 对应论文的软肋 | 模拟器给出的证据形式 |
|---|---|---|---|
| Q1 | **复现性**：用论文的模型去拟合同结构的数据，能否还原表 7 的 α、β？ | 无基线对比（B2）、无独立测试（B4） | 参数恢复散点图、MAE/MaxErr、伪 R² 对照表 |
| Q2 | **归因**：伪 R² 只有 0.61~0.77，是"数据噪声"还是"模型缺项"？各占多少？ | 拟合精度偏低却未深究（B9） | 分项消融：噪声 / 未建模直接效应 / 聚合方式 / 缺通信层，逐项开关后的 ΔR² |
| Q3 | **改进**：改哪一处收益最大？ | A1~A8 的改进方向全是"建议"，无验证 | 消融矩阵 + 效应量排序 |

**明确不做**：不做作战仿真的物理逼真度（弹道、雷达方程、气动），那是实验床的职责。本模拟器只保证**统计结构正确**——变量到指标有物理单调性、指标到 SE 的归一化语义正确、依赖传播机制与论文一致。

## 3. 总体架构

五层，层间只通过 DataFrame 契约耦合，任何一层都可被真实平台替换。

```
L0 结构层  net.py          节点/边/法术链/真值参数（表 7）
L1 变量层  variables.py    7 变量 + DOE（LHS/随机/单因素极端/定向注入）
L2 指标层  leaf_model.py   变量→表 5 指标→归一化 SE（源节点）
L3 真值层  leaf_model.propagate  真值 FDNA 聚合 + 未建模效应 + 随机性
L4 求解层  fit.py          SoD/CoD 参数拟合（DE + L-BFGS-B 多起点）
L5 分析层  run_demo.py     拟合评价 / 参数恢复 / 消融 / 级联与敏感性
```

数据流（一行 = 一次仿真实验）：

```
变量 x (7 维)  ──►  指标 m (6 维)  ──►  SE_src (6 维)  ──►  SE_all (11 维)
                                              │
                              ┌───────────────┴───────────────┐
                              ▼                               ▼
                     L4 拟合 (α,β,δ)×18               L5 分析（扫参图/级联）
```

## 5. 生成端设计（最关键，决定模拟器有没有意义）

### 5.1 绝不能"用 FDNA 生成、再用 FDNA 拟合"

如果内生节点 SE 直接由式 (10)~(12) 产生，拟合就是恒等映射，R²≡1、参数误差≡0，整个实验毫无信息量。**必须让生成机制比拟合模型更丰富**，制造"模型设定误差"（misspecification）。

本方案的生成端 = **结构项 + 未建模项 + 随机项**：

```
SE_j = min( mean_i[α*_ij·SE_i + 100(1-α*_ij)],  min_i[SE_i + β*_ij] )   ← 结构项（与论文同构）
       + g_j(x)                                                          ← 未建模直接效应
       + z_run/2 + ε_j                                                   ← 场域随机扰动 + 节点噪声
```

`g_j(x)` 刻意选取**没有入边可用**的物理效应，正是论文 5.4.1 自陈的"未考虑通信链路 / 未区分串并联 / 指标不精细"的具体化：

| 节点 | 未建模直接效应 | 物理含义（为什么 FDNA 结构上抓不到） |
|---|---|---|
| S5 / S6 | `+10·(u4−0.5)`, `+8·(u4−0.5)` | 浮游灵体探知分辨率直接决定跟踪质量，而不只通过 D4 的融合结果间接传递 |
| S5 / S6 | `−4·(u6−0.5)`, `−4·(u7−0.5)` | 目标防御/逃逸直接压缩跟踪窗口（交互环境无入边） |
| F7 | `−14·(u6−0.5) − 10·(u7−0.5)` | 舰船防阵强度与离场速度直接决定毁伤程度，**结构上 F7 只有 S5、S6 两条入边** |
| F9 / F11 | `+6·(u3−0.5)`, `+4·(u3−0.5)` | 暮影感知魔像探测范围提供的直接引导，未建为边 |

`u` 为 7 变量归一化后的能力值（越大越有利于圣光同盟）：

```
u1 = 1 − t_sat/30          u2 ∈ {1.0, 0.65, 0.35}（前出/侧翼/后方）
u3 = (R_awacs−200)/300     u4 = (R_uav−60)/60      u5 = (v_fusion−10)/50
u6 = (d_ship−1)/9          u7 = (v_ship−10)/25
```

### 5.2 指标层与归一化（SE 的语义）

源节点指标为"基准值 + 能力饱和响应"形式（指数 <1 表示边际收益递减），叠加 6% 相对测量噪声：

| 节点 | 指标 | 生成式 | 归一化 |
|---|---|---|---|
| S1 | 发现目标时间（cost） | `2 + 28·(1−0.6u1−0.4u3)^1.2` | `100·(30−T)/28` |
| D2 | 融合完成时间（cost） | `3 + 22·(1−0.75u5−0.25u3)^1.1` | `100·(25−T)/22` |
| S3 | 发现目标次数（benefit） | `2 + 18·(0.6u3+0.25u1+0.15u2)^1.2` | `100·(N−0)/20` |
| D4 | 融合完成时间（cost） | `3 + 24·(1−0.6u5−0.4u4)^1.1` | `100·(27−T)/24` |
| S8 | 有效发现锁定次数（benefit） | `1 + 12·(0.55u3+0.45u2)^1.1` | `100·N/13` |
| S10 | 有效锁定次数（benefit） | `1 + 10·(0.45u3+0.35u2+0.2u1)^1.1` | `100·N/11` |

> **设计取舍（须在论文中如实声明）**：内生节点（S5/S6/F7/F9/F11）的指标（有效跟踪时长、有效毁伤程度）**不单独建模**，其 SE 直接由真值依赖结构产生。这等价于假设"实验床测得的跟踪/毁伤指标，其归一化结果恰好由依赖关系决定"。若接入真实仿真平台，应改为**直接采集全部 11 个指标 → 归一化 → FDNA 只用于拟合**，此时生成端与拟合端才完全解耦（见 §11 适配器）。

### 5.3 两档真值参数

| 档位 | 用途 | 参数来源 |
|---|---|---|
| `PAPER` | 复现论文表 7、与论文 R² 对照 | 表 7 的 18 组 (α,β) |
| `DESIGN` | 可辨识性实验 / 方法对比 | 人工设定、保证 α、β 在参数空间充分分散，且刻意设置"高 α + 高 β"（逻辑悖论）与"低 α + 低 β"（隐形关键节点）等极端组合，用于检验 A6 的 α-β 一致性约束 |

## 6. 实验设计（DOE）

### 6.1 三块实验

| 块 | 名称 | 规模 | 设计方法 | 作用 |
|---|---|---|---|---|
| A | 变量驱动（主实验） | 6000 | **LHS 60%**（7 维空间填充，保证主效应与低阶交互可估）+ 均匀随机 25% + **单因素极端 15%**（每次推 1 个变量到 0/1 端） | 对应论文"6000 余次探索性仿真实验"，是 SE 分布的主体 |
| B | **定向节点效能调节** | 520 | 8 个节点（S1,D2,S3,D4,S8,S10,S5,S6）× 6 档（0/15/35/60/85/100）× 10 次 + 全高/全低基准 | 解决 β 的**可辨识性**（见 §8）；等价于论文图 8 的"0→100 扫参"，但**每条边都扫**而不是只扫 3 个接收节点 |
| C | 验证集 | 668（10%） | 从 A 中分层抽样 hold-out + 5 折交叉验证 | 弥补论文 B4（无独立测试集），并破除 B7（同一批数据既算 SE 又拟合参数） |

合计 **6520** 次，与论文"6000 余次"量级一致，便于横向对比。

### 6.2 为什么必须有 A 块的单因素极端点

`CoD = min_i(SE_i + β_i)` 在供给节点普遍高值时会**饱和**：当所有 SE_i ≈ 95，CoD ≥ 95 + min β，而 SoD ≈ 95，于是 `SE_j ≈ 95` 与 α、β 几乎无关。若实验数据集中在高绩效区间（真实作战实验的常见偏置），参数就会退化为"不可估"。单因素极端点的作用是把每个节点调至低端，让非线性/截断区被采样到。

### 6.3 边级覆盖度指标（新增的可诊断量）

对每条边定义覆盖度 `cov_e = #{t : e = argmin_i(SE_i+β_i)} / N`。**`cov_e = 0` 的边，其 β 不可辨识**。这是判断"实验设计是否够用"的直接标准，比看总样本量更有意义。

## 7. 求解端设计

### 7.1 可分离性：把 36 维联合优化拆成 5 个独立子问题

由式 (10)~(12)，接收节点 j 的预测只用到**供给节点的 SE**，与其它接收节点的参数无关。因此损失函数可分离：

```
min_{α,β,δ} Σ_j Σ_t [ SE_j^(t) − min(SoD_j^(t), CoD_j^(t)) − δ_j ]²
  ≡  Σ_j  min_{α_·j, β_·j, δ_j} Σ_t [ ... ]²
```

好处：① 5 个 2k+1 维（k=2/2/3/5/5）子问题并行求解；② 用**观测到的**供给节点 SE 而非拟合值，彻底避免误差沿链级联放大；③ 每个节点可独立报告伪 R²，与表 7 逐行对照。

### 7.2 优化策略（针对论文 C2"初值敏感"）

| 层 | 方法 | 理由 |
|---|---|---|
| 全局初值 | **差分进化（DE, Sobol 初始化）** | min() 使目标分片光滑、局部极小密集，梯度法单起点易被困 |
| 精修 | **L-BFGS-B**，区间 `α∈[0,1]`、`β∈[0,100]`、`δ∈[−10,10]` | 与论文一致，便于对比 |
| 稳健化 | 8 组随机起点 + DE 结果，取最优 | 复现论文"结果对初值敏感"，并证明多起点可消除 |
| 评价 | 伪 R²、RMSE、**参数恢复误差**（有真值才能算，这是论文没有的） | 论文只有 R² 和残差图 |

### 7.3 一个必须实现的剔除规则

被注入的节点 j，其观测 SE 是人工改写的，**不满足依赖模型**。若把 `attuned_node == j` 的样本仍用于拟合 j，会引入系统性偏差。实测：未剔除时 S5/S6 的 β 全部上偏 **约 +8**，α 的 MAE 从 0 恶化到 0.063。**这类"实验设计与模型假设冲突"的样本必须从对应子问题中剔除。**

## 8. 可辨识性分析（本方案的核心结论）

### 8.1 机制

- **α 恒可辨识**：SoD 项 `α·SE_i + 100(1−α)` 在所有样本上都生效，且有 `100(1−α)` 的基线偏移，只要 SE_i 有变化就能定出 α。
- **β 仅在被绑定时可辨识**：`min_i(SE_i+β_i)` 只暴露 argmin 那条边。对非 argmin 边，数据只给出不等式约束 `β_i ≥ SE_j^obs − SE_i`，β_i 可向上漂移到区间上界。**这不是优化器的问题，是信息问题。**

### 8.2 实测（本原型，真值 = 表 7）

| 场景 | 样本 | α MAE | α MaxErr | β MAE | β MaxErr | 说明 |
|---|---|---|---|---|---|---|
| 无噪 + 仅变量驱动 | 600 | 1e-5 | 8e-5 | **8.87** | **37.6** | α 精确恢复，β 大面积漂移（S10→F11 真值 81 被拟合为 43） |
| 无噪 + 变量驱动 + 定向注入 | 920 | **0.0** | **0.0** | **0.0** | **0.0** | **36 个参数全部精确恢复**，验证生成/拟合链路无偏 |
| 真实（含未建模项+噪声）+ 无注入 | 6000 | 0.115 | 0.364 | **9.86** | 31.8 | 论文实际采用的做法 |
| 真实 + 定向注入 | 6520 | 0.093 | 0.319 | **1.18** | 5.57 | β 误差降 88% |

**结论 1**：无噪情形下 β 的零误差恢复，证明了"定向注入使每条边至少当一次瓶颈"是**充分**的。
**结论 2**：真实情形下 β MAE 从 9.86 降到 1.18，说明论文"初值敏感 + 精度一般"的根因之一**不是算法，而是实验设计没有覆盖 argmin 切换区**。

### 8.3 残余误差的来源（诚实说明）

真实模式下仍有 α MAE ≈ 0.09，这是**未建模直接效应被参数吸收**所致，属预期行为。若把 `gamma` 置 0（关闭未建模项），α 恢复到 1e-5 量级。这正是 §9 消融矩阵要定量测量的东西。

### 8.4 S5 / S6 的结构性共线

S5 与 S6 的上游完全重合（同为 S1、D2、D4，α 向量仅差 0.03~0.08），导致二者 SE 高度相关，`β_{S5→F7}` 与 `β_{S6→F7}` 只能得到"和"的约束。把注入扩展到内生节点（直接调节 S6 而保持 S5）后，这一对才被分开。

**给论文的建议**：若要分离这两个轰炸机/无人机编队的 β，需引入**能独立区分二者的变量**（如各自阵位、续航时间、被干扰概率），否则应在文中报告参数的**联合置信域**而非点估计。

## 9. 消融 / 反事实矩阵（把 A/B/C 类不足变成开关）

每个开关独立可调，输出 `ΔR²`、`Δ(参数恢复误差)`、`Δ(结论稳健性)` 三列。

| 开关 | 对应不足 | 实现方式 | 预期效应 | 度量 |
|---|---|---|---|---|
| `link_layer` | A5 未考虑通信链路 | 在每条边插入 relay 节点，SE_relay = f(距离, 带宽, 干扰)；改为两跳传播 | R² 上升，β 物理含义更清晰 | ΔR²、β 偏移 |
| `series_parallel` | A3 未区分串并联 | 冗余组用 `1−Π(1−SE_i)` 聚合代替 min；串联用 min | 冗余价值被正确体现，关键节点排名变化 | 关键节点排序 Spearman |
| `agg_operator` | A2 均值掩盖 | 均值 → 加权均值 / 几何均值 / 幂均值 | "少而关键"节点敏感度上升 | 敏感性曲线斜率 |
| `nonlinear` | A1 线性假设 | SoD 项换 S 型：`100·σ(k(SE_i−θ))` | 阈值/饱和段拟合改善 | 分段残差 |
| `delta_mode` | A8 δ 语义模糊 | `off` / `bounded` / `per-edge` 三档 | δ 大 = 模型缺项多（实测：无注入时 δ 由 1.7 涨到 3.3，正好吸收 β 的偏差） | `|δ|` 与 R² 的相关性 |
| `consistency` | A6 α-β 悖论 | 加约束 `β ≥ 100(1−α) − c`，或加联合先验 | 剔除"高依赖+低约束"矛盾解 | 约束违反率 |
| `init_strategy` | C2 初值敏感 | `PCA`（论文）/ `random` / `DE+多起点` 三档，各跑 20 个种子 | 量化"初值敏感"到底多大 | R² 与 β 的跨种子标准差 |
| `holdout` | B4 / B7 无独立验证 | 5 折交叉验证 + 独立测试集 | 暴露过拟合程度 | 训练/测试 R² 差 |
| `fault_block` | 本文新增 | 开/关定向注入 | 见 §8.2 | β MAE |
| `noise_level` | B8 无误差传播 | 扫描 `σ_ind/σ_run/σ_node` | 给出参数置信区间 | Bootstrap CI 宽度 |

> 这张表把"论文的不足"转化为"可执行的实验计划"，也是后续小论文/毕设章节的骨架。

## 11. 与真实仿真平台的接口（Adapter 契约）

模拟器的价值上限取决于它能否替换成真平台。约定一个最小接口：

```python
class SimPlatformAdapter:
    def reset(self, scenario: dict) -> None: ...
    def run(self, variables: dict) -> dict:      # 一次实验
        """返回 {"ind_S1": float, "ind_D2": float, ..., "ind_F11": float}
        要求：同一 variables 下可复现（种子可控）；支持 fault 注入参数。"""
    def inject_fault(self, node: str, level: float) -> None: ...
```

替换后，`leaf_model.py` 整体下移为"指标采集器"，`propagate()` 关闭（不再由真值 FDNA 生成内生节点），此时：

- **生成端** = 真平台（黑箱，含全部物理效应）
- **拟合端** = FDNA（白箱近似）
- 二者差异才是**真实的模型设定误差**，R² 才有物理意义

这也是本方案与论文的**根本区别**：论文用真平台生成、用 FDNA 拟合（无法知道真值，故只能看 R²）；本方案先用"已知真值的模拟器"**校准拟合器**，确认它无偏、可辨识，再接真平台。**没有这一步，任何"R²=0.7 说明方法有效"的论断都缺一个必要的对照。**

## 12. 风险与遗留

| # | 风险 | 影响 | 处置 |
|---|---|---|---|
| R1 | 未建模项 `g_j(x)` 系数是人工设定，缺乏依据 | 消融的 ΔR² 只有相对意义 | 用论文残差图（图 7）反推量级，标定到同量级后再做消融 |
| R2 | 指标响应函数是解析式，非物理模型 | 变量→SE 的映射可能过于光滑 | 接入真平台后自动消失；过渡期可加阈值/饱和/死区 |
| R3 | β 在低覆盖度边上仍不可辨识 | 参数表出现"虚假精确" | 强制报告 `cov_e` 与 Bootstrap 置信区间，`cov_e<K` 的边标灰 |
| R4 | 未处理指标共线（B6） | 归一化后的 SE 可能重复计权 | 指标层加 PCA/相关筛选，或在 SE 计算时用熵权/CRITIC |
| R5 | 单场景（B1） | 结论不可外推 | 变量范围与网络结构做成配置，支持多场景批量跑 |
